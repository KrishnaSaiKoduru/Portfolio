# Krishna Sai Koduru — Portfolio

A cinematic, single-page portfolio for **Krishna Sai Koduru**, Data Engineer & AI builder.

🔗 **Live site:** https://krishnasaikoduru.github.io/Portfolio/

## About

A self-contained, immersive portfolio featuring a video hero, a Three.js
ambient particle layer, GSAP-driven motion, and sections covering About,
Career, Projects, Products, Skills, and Points of Interest.

Everything — markup, styles, scripts, fonts reference, and media — is compiled
into a single `index.html` file, so it deploys anywhere with zero build step.

## Deploy on GitHub Pages

1. Push `index.html` to the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then **Save**.
5. The site goes live at `https://<username>.github.io/<repo>/` within a minute.
